- JavaScript functionality
- Interactive elements

---

## ⚠️ Challenges Faced

### 1. CSS Alignment

Maintaining proper alignment and spacing between different website elements required careful adjustments.

**Solution:**  
CSS properties were modified and the website was repeatedly tested in the browser.

### 2. Responsive Design

Ensuring that the website displayed correctly on different screen sizes required additional testing.

**Solution:**  
Responsive CSS techniques were applied and tested across different screen sizes.

### 3. JavaScript Debugging

Some interactive features did not work correctly during the initial implementation.

**Solution:**  
The code was reviewed, errors were identified, corrections were made, and the features were tested again.

### 4. Code Organisation

Managing HTML, CSS, and JavaScript files consistently became important as the project progressed.

**Solution:**  
Visual Studio Code was used to organise and manage the project files.
